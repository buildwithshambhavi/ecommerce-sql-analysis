# 🛒 E-Commerce Business Analysis using SQL

## 📌 Project Overview

This project presents an end-to-end SQL-based business analysis of a simulated e-commerce platform.  
The objective is to analyze transactional data and generate actionable business insights using MySQL.

The analysis focuses on revenue performance, customer behavior, product profitability, payment trends, the impact of discounts, and advanced analytics using SQL window functions.

This project simulates real-world business intelligence reporting and KPI tracking in an e-commerce environment.

---

## 🗂 Dataset Information

The dataset used in this project was synthetically generated using Python for learning and portfolio purposes.  
It is designed to closely resemble real-world e-commerce operations and business scenarios.

The dataset includes:

- Customers
- Orders
- Order Items
- Products
- Payments

## 📈 Key Insights

- The platform generated approximately **₹74.7M in total revenue**, indicating strong business scale.
- The Average Order Value (AOV) is approximately **₹14.9K**, reflecting mid-to-high value transactions.
- Monthly revenue remains stable (₹5.9M–₹6.6M), demonstrating consistent performance.
- A small group of high-value customers contributes a significant portion of total revenue.
- Sports and Electronics are the top revenue-generating categories.
- Discounted orders account for a large share of revenue, suggesting strong reliance on promotional strategies.
- Return and cancellation patterns highlight potential operational improvement areas.
